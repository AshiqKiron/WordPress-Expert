# WordPress Legacy Documentation & Learning Platforms

- **Deprecated Functions & Hooks**: `get_page_by_title()`, `screen_icon()`, `wp_embed_register_handler()`

- **Archive Access Guidelines**: Read-only status, no new edits, citation warnings for deprecated patterns
